# 📊 Regional Sales Analysis Project (MySQL + Excel)

## 📌 Project Overview

This project analyzes regional sales data using MySQL and Microsoft Excel. The objective is to clean, process, and visualize sales data to identify trends in revenue, product performance, customer behavior, and regional performance.

This is a beginner-level data analytics project demonstrating end-to-end workflow from data import to SQL analysis and Excel dashboard creation.

---

## 🎯 Objectives

- Import and structure CSV data in MySQL
- Perform SQL-based data analysis
- Identify key business insights
- Build an interactive Excel Dashboard
- Visualize sales performance using charts and KPIs

---

## 🛠️ Tools Used

- MySQL
- Microsoft Excel
- CSV Dataset

---

## 📂 Dataset Information

**Dataset Name:** RegionalSales2025.csv  
**Total Records:** 1000  

### Columns Description:

- OrderID → Unique order identifier  
- Date → Order date  
- CustomerID → Unique customer ID  
- Region → Sales region (North, South, East, West)  
- ProductName → Product sold  
- Category → Product category  
- Quantity → Number of items sold  
- UnitPrice → Price per unit  
- TotalAmount → Total order value  
- OrderStatus → Status (Completed, Cancelled, Returned)  
- SalesAgent → Responsible sales agent  

---

## 🧮 SQL Analysis Performed

### 1. Sales Performance
- Total sales calculated using SUM of TotalAmount
- Region-wise performance analysis

### 2. Order Status Analysis
- Count of Completed, Cancelled, and Returned orders

### 3. Revenue Loss Analysis
- Identified revenue loss due to cancelled and returned orders

### 4. Product Analysis
- Category-wise revenue contribution
- Top performing products

### 5. Customer Analysis
- Repeat customers identified based on order frequency

---

## 📈 Excel Dashboard

An interactive Excel dashboard was created using Pivot Tables and Charts.

### KPI Cards

- Total Completed Sales  
- Total Cancelled Orders  
- Average Order Value  
- Most Returned Product  

### Visualizations

- Sales by Region and Category (Heatmap)
- Order Status by Region (Stacked Bar Chart)
- Monthly Sales Trend (Line Chart)

### Interactive Filters (Slicers)

- Region  
- Category  
- SalesAgent  

---

## 📊 Key Insights

- North region recorded the highest number of orders  
- Electronics category generated the highest revenue  
- Jacket was the most returned product  
- Average order value was approximately ₹47,573  
- Cancelled and returned orders contributed to revenue loss
